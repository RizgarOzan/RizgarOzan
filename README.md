### 🧩 Now: Match3 Lab

A match-3 **workbench**, not a match-3 game — an engine-independent C# rules core, a readable
level format, a Unity level editor, and a bot simulator that tells you how hard a level is
before anyone plays it.

| level | greedy bot win % | random bot win % |
|---|---|---|
| 01 First Steps | 100.0 | 70.1 |
| 03 Crates | 90.8 | 27.3 |
| 05 Hourglass | 59.7 | 9.1 |
| 06 Cold Storage | 49.7 | 3.1 |

12,000 games in about five seconds; 39 xUnit + 2 play-mode tests; every rule decision written
down with its reason. → [RizgarOzan/match3-lab](https://github.com/RizgarOzan/match3-lab)
